# ➕ Soma Swing - Java

## 📖 Sobre o projeto

Este projeto foi desenvolvido em Java utilizando Swing para realizar a soma de dois números informados pelo usuário através de uma interface gráfica.

O objetivo é praticar a criação de interfaces gráficas, manipulação de eventos e lógica de programação utilizando a linguagem Java.

## 🚀 Tecnologias utilizadas

- Java
- Java Swing
- Maven
- NetBeans

## 🎯 Objetivo

Praticar:

- Programação Orientada a Objetos (POO)
- Desenvolvimento de interfaces gráficas com Swing
- Manipulação de eventos
- Operações matemáticas
- Organização de projetos Java

## ▶️ Como executar

1. Clone este repositório.
2. Abra o projeto no NetBeans.
3. Execute a aplicação.
